# Owned synthetic samples

These two finite baseline exports and the `internal/growthlab/ui` business
application were authored for local engineering tests under the repository's
Apache-2.0 license. They contain generated counts and identifiers only. No
external content, personal information, paid transactions, consent, independent
annotations, elapsed real-user pilot, or causal benefit is represented.

The committed JSON files are schema examples with explicit synthetic catalog
pins, not imports for an existing workspace. The lab generates usable goal +
baseline pairs with its actual immutable catalog hashes in its private
`DATA_DIR/samples/activation.json` and `upgrade.json`. Use those pairs in the
workbench. Do not replace pins to make unrelated evidence appear valid.

See [the lab runbook](../../docs/growth-synthetic-lab.md) for startup, the normal
approval flow, browser checks, virtual D1 maturity, recovery and study preparation.
