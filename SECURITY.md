# Security policy

Security fixes are developed on `main`. The maintainers evaluate backports to tagged releases case by case.

## Report a vulnerability

Use GitHub's [private vulnerability reporting](https://github.com/saker-ai/grayling/security/advisories/new) to contact the maintainers. Include the affected version, impact, reproduction steps, and a suggested fix if available. Do not post exploit details or credentials in a public issue or pull request.

For ordinary bugs and feature requests, use [GitHub Issues](https://github.com/saker-ai/grayling/issues). Deployment guidance and known trust boundaries are documented in the [threat model](docs/threat-model.md).
