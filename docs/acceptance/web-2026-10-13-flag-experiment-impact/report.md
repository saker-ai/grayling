# Flag 关联实验与发布复核验收（2026-10-13）

## 本次交付

Flag 详情 API 的 `experimentImpact` 读取同工作空间、同环境中 `FlagKey` 相同的实验，返回完整计数及最多 20 条关系。运行中和暂停中的实验排在前面；每条记录包含实验 ID、状态、epoch、登记时的 Flag revision 和更新时间。发布预览也带同一份关系摘要。它说明“哪些实验登记了此 Flag”，不把关系数误称为受影响用户数或当前流量。

控制台在 Flag 详情显示关联实验并可进入实验工作台。发布确认框打开时重新读取 Flag；提交前再读取草稿、当前 revision 与关联实验。任一复核依据变化则更新确认内容、保留理由并要求再次确认。服务端仍对草稿内容与基线 revision 执行既有发布检查。
