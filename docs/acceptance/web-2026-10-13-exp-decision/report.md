# 实验详情首屏决策摘要验收（2026-10-13）

## 范围与环境

本轮在本地真实 Grayling 服务 `127.0.0.1:19089`、Acceptance / Production 工作空间与环境中，使用浏览器打开运行中的 `exp-8`。该实验尚无实际随机曝光；报告来自服务端 `/api/v1/admin/experiments/exp-8/report`，不是前端示例数据。

## 结果

| 场景 | 页面结果 | 证据 |
| --- | --- | --- |
| 运行中、无曝光 | 打开详情后首屏自动显示 HOLD、`no randomized exposures recorded yet` 等服务端阻断原因、报告生成时间和数据水位；完整报告仍需点击“Load / refresh report” | [桌面 1440px](desktop.png)、[手机 390px](mobile.png) |
| 报告读取失败 | 浏览器将该 GET 请求模拟为 503 后重新进入详情；首屏显示“Current analysis is unavailable”，没有把旧的健康报告作为当前结论 | 浏览器交互验证；合成故障，不代表服务端真实故障 |
| 未启动、读取失败的渲染契约 | 未启动显示尚无实验结果；刷新失败且已有旧健康报告时不输出旧的健康判定 | `web/render_contract.mjs`，由 `go test ./web` 执行 |

截图中的 HOLD 同时包含数据管道与 SRM 诊断。页面逐字展示服务端原因，本轮没有重定义这些报告判定的计算规则。生成时间与水位按浏览器本地时区显示，原始时间保留在 `<time title>` 中。

## 验证

- `GOWORK=off go test ./web -count=1`：通过。
- 浏览器在 390px 与 1440px 宽度下核对首屏、状态和完整报告的按需展开。
