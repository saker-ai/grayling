# 总览实验风险摘要验收（2026-10-13）

## 真实服务

本地 Grayling 服务的 Acceptance / Production 环境有 3 个实验，其中 `exp-8` 正在运行且尚无随机曝光。总览通过 `/experiment-summaries?limit=50` 读取服务端报告摘要；桌面和 390px 手机页面均显示 `exp-8`、真实的 `no randomized exposures recorded yet` 阻断原因以及检查覆盖范围：[桌面截图](desktop.png)、[手机截图](mobile.png)。

## 故障注入

浏览器拦截并中止摘要请求后点击“Refresh status”：页面保留暂停实验数 `0`、运行实验数 `1`、待审批数 `0` 和已发布 Flag 数 `2`，同时显示局部故障及“报告健康状态无法检查”。随后修正空状态文案：数据不完整时不再宣称“暂无紧急事项”，而提示重试。故障为浏览器合成，不是服务端真实故障。

## 边界

总览只汇总最近更新的最多 50 个实验的可用报告；超过 50 个时明确标注覆盖数量并提供进入完整实验列表的入口。未启动实验没有报告；无 `report.read` 权限时提示健康状态不可见。完整风险聚合、跨身份验收和 50 个以上实验的真实浏览器场景仍待实施。
