# GoLab 实施状态

> 对照 [技术方案](技术方案.md) 的落地状态记录。本文如实区分**已实现并验证**、**部分实现**与**未实现**；所有"已验证"结论均对应仓库内可重复运行的测试。最后更新：2026-09-25。

## 总体状态

单节点可运行的完整闭环已实现：管理 API（草稿→审核→发布→回滚）、gonacos 配置底座分发（不可变 revision + manifest + 读回验证）、Go SDK（本地求值 + SSE/轮询同步 + 陈旧兜底 + 曝光批量上报）、实验与统计（epoch/互斥层/曝光归因/SRM/固定样本决策）、AI 资源灰度（所有权索引/版本 pin/摘要校验/会话冻结/紧急撤销）、内嵌 Web 控制台。生产化扩展已落地：**PostgreSQL 存储后端**（版本化 schema 迁移、单元级聚合表、事件按月 RANGE 分区+按分区删除保留期、HMAC 密钥环轮换迁移；全部测试连**真实 PostgreSQL**——docker/GOLAB_TEST_PG_DSN）、**独立 proxy 部署形态**（cmd/golab-proxy：eval/SSE/collect/config 无状态中继 + liveness/readiness 健康检查 + 超时/连接池，双进程 boot 测试）、**OpenFeature Go Provider**（pkg/ofprovider：官方 go-sdk v1.19 FeatureProvider/StateHandler/EventHandler，基于官方 isolated API 的契约用例含曝光归因全链路）；gonacos 依赖已从 sibling replace 固定为**确定 commit 伪版本**并重跑契约测试。

**未做**：多语言 SDK、自动推进发布、高级统计（ratio/CUPED/序贯/贝叶斯/judge/Bandit）、Traefik 集成、gonacos 多节点集群验证。

## 性能证据（待测目标口径，§13）

- 本地求值：`BenchmarkLocalEvaluation` 均值 **2102 ns/op**（500 flags、3 条定向规则+segment+百分比默认规则；Intel Xeon E5-2673 v4 @2.30GHz；2000 次采样）。P99<1ms 目标在该均值下大概率成立，但**正式 P99 需压测报告**，未宣称达成。
- 快照编译：`BenchmarkSnapshotBuild` 均值 10.4 ms / 500 flags（每个 manifest revision 一次，非热路径）。
- 发布→SDK 可见：E2E 断言 5s 内（SSE 推送路径；方案 2s 目标未做正式计时压测）。

## 已知限制与生产前必办

1. **平台存储**：PostgreSQL 后端已实现并经真实 PG 测试（schema 迁移/聚合表/事件分区删除/密钥轮换迁移，`cmd/golab -pg <DSN>`）；文件 JSON 仍是开发默认。**备份/恢复联合演练**（gonacos Snapshot + PostgreSQL + 密钥同一恢复点）仍未做；密钥轮换的 `Store.RotateHMACKey` 目前只有存储层入口，未暴露管理 API（轮换是运维迁移，需要审计流程后再开）。事件原始记录内存工作集上限 20 万条（PG 侧按保留期分区存储不受此限，去重账本覆盖全保留期）。
2. **单节点**：gonacos 集群模式（外部 Redis）、GoLab 多副本对账未验证；PostgreSQL 后端的读路径服务自内存工作集（单节点拓扑），多副本需要读扩散/失效协议。
3. **无 LICENSE**：gonacos 正式许可未确认前不得对外多租户生产（§12.5）。gonacos 依赖已 pin 确定 commit（`v0.0.0-20260706000526-514208bd40a1`），升级需重跑契约/兼容测试。
4. 比例变更会移动用户（固定模特性）；需要跨比例粘性时用新 epoch——持久 sticky 存储未实现。
5. 实验报告仅双臂、单主指标、固定样本；多次查看 p 值不得用于提前宣布胜利（决策门已按此设计）。归因窗口当前由采集侧 72h 硬边界约束；**按实验预注册 AnalysisWindow 过滤聚合**仍未做（聚合为增量式，不做窗口内重建；PG 后端的原始事件分区为后续窗口重算保留了数据基础）。
6. 浏览器场景请使用 `/api/v1/sdk/eval` 远程求值（可经 `cmd/golab-proxy` 独立部署）；SDK 全量快照含内部规则，不要下发浏览器。
