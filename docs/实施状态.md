# GoLab 实施状态

> 对照 [技术方案](技术方案.md) 的落地状态记录。本文如实区分**已实现并验证**、**部分实现**与**未实现**；所有"已验证"结论均对应仓库内可重复运行的测试。最后更新：2026-09-25。

## 总体状态

单节点可运行的完整闭环已实现：管理 API（草稿→审核→发布→回滚）、gonacos 配置底座分发（不可变 revision + manifest + 读回验证）、Go SDK（本地求值 + SSE/轮询同步 + 陈旧兜底 + 曝光批量上报）、实验与统计（epoch/互斥层/曝光归因/SRM/固定样本决策）、AI 资源灰度（所有权索引/版本 pin/摘要校验/会话冻结/紧急撤销）、内嵌 Web 控制台。生产化扩展已落地：**PostgreSQL 存储后端**（版本化 schema 迁移、单元级聚合表、事件按月 RANGE 分区+按分区删除保留期、HMAC 密钥环轮换迁移；全部测试连**真实 PostgreSQL**——docker/GOLAB_TEST_PG_DSN）、**独立 proxy 部署形态**（cmd/golab-proxy：eval/SSE/collect/config/revision 无状态中继 + liveness/readiness 健康检查 + 超时/连接池，双进程 boot 测试）、**OpenFeature Go Provider**（pkg/ofprovider：官方 go-sdk v1.19 FeatureProvider/StateHandler/EventHandler，基于官方 isolated API 的契约用例含曝光归因全链路）；gonacos 依赖已从 sibling replace 固定为**确定 commit 伪版本**并重跑契约测试。阶段二已落地：**Python SDK**（`sdk/python`，远程求值+revision 轮询缓存+collect 契约事件上报，pytest 集成测试连**真实 golab 二进制**）、**TypeScript SDK**（`sdk/typescript`，同契约，node:test 原生跑 .ts，集成测试连真实二进制；两语言均含 golab-fnv1a-10000-v1 独立实现并逐条通过黄金向量）、**自动推进发布**（`internal/rollout`：预注册计划步骤/观察窗/决策门驱动的 eligibility 分步放量，动作幂等、可暂停、人工接管开关，fake-clock 测试覆盖时钟推进与 SRM/护栏阻断）、**P0 收尾**（根目录 `openapi.yaml` 由 `internal/api/openapi_test.go` 与路由表 AST 机械化双向核对；`docs/threat-model.md` 代码取证威胁模型；`test/perf` 正式压测——本地求值 P99=3.68µs、发布→SDK 可见 max=3.77ms、1000 并发 SSE fan-out p99≤5.7ms（两轮），见"性能证据"节）。阶段三（P5 统计部分）已落地：**高级统计引擎**（`internal/stats` 扩展 ratio delta-method、quantile、CUPED、序贯 mSPRT、贝叶斯后验；`internal/bandit` Thompson/ε-greedy 流量分配+安全冻结；`internal/judge` LLM-as-judge 管道+离线校准+护栏接入）——每种方法均有独立数值验证（对照解析解/权威实现/蒙特卡洛）与固定种子模拟验证（I 型错误/覆盖/功效/regret 落预注册区间），新指标类型接入既有决策门且 SRM/护栏阻断对其生效，贝叶斯/序贯与频率派结论**分离呈现**（详见"P5 统计方法验证证据"节）。

**未做**：Traefik 集成、gonacos 多节点集群验证、审批强化（P4 余项）、自动推进的控制台 UI（当前经 API/引擎运行，计划与历史可在实验详情 JSON 查看）、统计的 Holm 多重比较与 funnel/retention 指标。（P5 高级统计——ratio/quantile/CUPED/序贯/贝叶斯/judge/Bandit——已实现并验证，见 §10.3/§10.4 行与"P5 统计方法验证证据"节。）

**决策门集成证据**（`internal/experiment/report_p5_test.go`、`internal/platform/experiments_p5_test.go`、`internal/judge/judge_test.go`）：

- 新指标类型可预注册：ratio（需 denominatorKey）、quantile（需 quantileLevel∈(0,1)）、mean+covariateKey（CUPED）经 `CreateExperiment` 校验通过；缺字段/非法值/未知 type/未知 analysisMethod 一律 `ErrValidation`（有测试）。
- **SRM/护栏阻断对新方法同样生效**：ratio 指标在倾斜入组（400 vs 640）下 SRM 告警 → verdict **hold**、报告 unhealthy；quantile 指标 + 比例护栏破线 → verdict **rollback**（决策门顺序不变）。
- **judge 作为护栏接入决策门**：未校准 judge 的大幅回退 → `QualityGuardrail` 恒 `breached=false`（只作诊断，`stats.Decide` 不回滚）；已校准 judge + 回退超阈 → `breached=true` → `stats.Decide` 判 **rollback**（§10.4）。
- **贝叶斯/序贯与频率派分离**：mean 报告同时产出 `Primary`（welch，驱动决策门）、`Sequential`（always-valid，不驱动门）、`Bayesian`（后验/期望损失/胜出概率，独立字段）；控制台 `renderReport` 对三者分区渲染并标注"separate view / not the decision gate"（DOM 契约测试 6 种报告形态全通过）。
