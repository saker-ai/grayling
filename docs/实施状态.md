# GoLab 实施状态

> 对照 [技术方案](技术方案.md) 的落地状态记录。本文如实区分**已实现并验证**、**部分实现**与**未实现**；所有"已验证"结论均对应仓库内可重复运行的测试。最后更新：2026-09-24。

## 总体状态

单节点可运行的完整闭环已实现：管理 API（草稿→审核→发布→回滚）、gonacos 配置底座分发（不可变 revision + manifest + 读回验证）、Go SDK（本地求值 + SSE/轮询同步 + 陈旧兜底 + 曝光批量上报）、实验与统计（epoch/互斥层/曝光归因/SRM/固定样本决策）、AI 资源灰度（所有权索引/版本 pin/摘要校验/会话冻结/紧急撤销）、内嵌 Web 控制台。

**未做**：多语言 SDK、OpenFeature Provider、PostgreSQL 后端、独立 proxy、自动推进发布、高级统计（ratio/CUPED/序贯/贝叶斯/judge/Bandit）、Traefik 集成、gonacos 多节点集群验证。

## 性能证据（待测目标口径，§13）

- 本地求值：`BenchmarkLocalEvaluation` 均值 **2102 ns/op**（500 flags、3 条定向规则+segment+百分比默认规则；Intel Xeon E5-2673 v4 @2.30GHz；2000 次采样）。P99<1ms 目标在该均值下大概率成立，但**正式 P99 需压测报告**，未宣称达成。
- 快照编译：`BenchmarkSnapshotBuild` 均值 10.4 ms / 500 flags（每个 manifest revision 一次，非热路径）。
- 发布→SDK 可见：E2E 断言 5s 内（SSE 推送路径；方案 2s 目标未做正式计时压测）。

## 已知限制与生产前必办

1. **gonacos 依赖未 pin commit**（sibling replace）；发布前固定版本并重跑 `test/smoke` 契约测试（§12.1）。
2. **平台存储为文件 JSON**：单机、全量落盘；生产需 PostgreSQL 后端（接口面已按单事务单元设计）。事件原始记录内存上限 20 万条（聚合不受限）。
3. **单节点**：gonacos 集群模式（外部 Redis）、GoLab 多副本对账未验证。
4. **无 LICENSE**：gonacos 正式许可未确认前不得对外多租户生产（§12.5）。
5. 比例变更会移动用户（固定模特性）；需要跨比例粘性时用新 epoch——持久 sticky 存储未实现。
6. 实验报告仅双臂、单主指标、固定样本；多次查看 p 值不得用于提前宣布胜利（决策门已按此设计）。归因窗口当前由采集侧 72h 硬边界约束；**按实验预注册 AnalysisWindow 过滤聚合**待 PostgreSQL 后端一并实现（首版聚合为增量式，不做窗口内重建）。
7. 浏览器场景请使用 `/api/v1/sdk/eval` 远程求值；SDK 全量快照含内部规则，不要下发浏览器。
